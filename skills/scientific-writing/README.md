## Quick Start

1. **Customize Configuration**:
   - Edit `latex/config/packages.tex` to add required packages
   - Edit `latex/config/commands.tex` for custom commands

2. **Write Content**:
   - Start with `latex/sections/introduction.tex`
   - Reference figures in `latex/figures/` and tables in `latex/tables/`
   - Manage citations in `latex/references.bib`

3. **Compile Document**:
   - Use your preferred LaTeX editor to compile `latex/main.tex`
   - Or run: `cd latex && pdflatex main.tex`

4. **Track Progress**:
   - Save drafts in `drafts/`
   - Store analysis scripts in `scripts/`
   - Keep data in `data/`

## Tips

- Use version control (Git) to track changes
- Keep bibliography entries organized in `.bib` file
- Use descriptive file names for all assets
- Regularly backup important work
