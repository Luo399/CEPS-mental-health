# 国内数据库参考

## CSMAR（国泰安）

### 主要数据库模块

| 模块 | 主要表 | 典型字段 |
|-----|-------|---------|
| 公司金融 | 资产负债表、利润表、现金流量表 | 总资产、营业收入、净利润、负债 |
| 股票市场 | 日交易数据、月交易数据 | 收盘价、成交量、市值、换手率 |
| 公司治理 | 股权结构、高管薪酬、董事会 | 持股比例、董事会规模、独董比例 |
| 行业数据 | 行业分类、行业财务 | 行业代码、行业平均ROE |

### 常用数据表

- `资产负债表_Annual`：企业资产负债数据
- `利润表_Annual`：企业盈利数据
- `股票日交易_De`：每日行情数据
- `股东持股`：股权结构数据
- `治理结构`：董事会、监事会数据

## Wind（万得）

### 主要产品

| 产品类型 | 数据内容 |
|---------|---------|
| 债券数据库 | 债券发行、交易、评级 |
| 宏观数据库 | GDP、CPI、M2等宏观指标 |
| 行业数据库 | 行业景气度、产能利用率 |
| 基金数据库 | 净值、持仓、重仓股 |

### 常用数据

- 债券到期收益率曲线
- 行业财务指标汇总
- 基金经理持仓数据

## 统计年鉴数据

### 中国统计年鉴

- 来源：国家统计局
- 频率：年度
- 内容：国民经济核算、人口、就业、固定资产投资、对外贸易等

### 省级统计年鉴

- 来源：各省统计局
- 频率：年度
- 内容：省份经济、社会发展数据

### 城市统计年鉴

- 来源：城市统计局
- 频率：年度
- 内容：城市经济、产业发展、城市建设

### 行业统计年鉴

- 来源：各部委/行业协会
- 内容：工业、农业、服务业各细分行业数据

### 数据获取

| 年鉴类型 | 获取方式 |
|---------|---------|
| 中国统计年鉴 | 国家统计局官网、CNKI |
| 省级统计年鉴 | 各省统计局官网、统计年鉴数据库 |
| 城市统计年鉴 | 城市统计局、年鉴网 |
| 行业统计年鉴 | 行业协会官网、图书馆
