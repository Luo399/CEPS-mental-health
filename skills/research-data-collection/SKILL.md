# 科研数据搜集与整理

## 概述

本skill帮助用户完成经管/金融研究的数据准备工作。对于可获取的数据（统计年鉴、公开数据集、API等），直接读取并保存；对于需认证/付费的数据，生成详细获取指南。

---

## 工作流程

### Step 1: 研究设计建议

基于用户提供的选题，执行以下步骤：

1. **确定研究范围**：时间跨度、行业、地域
2. **确定研究对象**：企业/行业/省份/国家/个体
3. **识别变量**：
   - 被解释变量（Y）
   - 核心解释变量（X）
   - 控制变量

输出：将变量清单整理为变量映射表的基础结构

### Step 2: 变量测度建议

为每个变量提供测度方案：

| 项目 | 内容 |
|-----|------|
| 测度方式 | 具体计算方法或指标定义 |
| 文献来源 | 经典文献或权威来源 |
| 可选方案 | 同一变量的其他测度方式及优缺点 |
| 选择建议 | 根据研究目的推荐合适方案 |

### Step 3: 数据获取与下载

#### 3.1 数据源分类与获取策略

| 数据类型 | 获取方式 | 处理方式 |
|---------|---------|---------|
| 统计年鉴/公开报告 | WebFetch抓取网页表格或PDF数据 | 解析并保存为CSV/Excel |
| 公开API（如World Bank） | WebFetch调用API | JSON解析后保存 |
| 数据库官网免费数据 | WebFetch下载页面/链接 | 解析下载并保存 |
| 需认证/付费数据 | 生成数据获取指南 | 记录表名、字段名、申请流程 |
| 用户需手动补充 | 记录变量来源 | 提供模板供用户填写 |

#### 3.2 实际数据获取执行

对于可获取的数据，执行以下操作：

**统计年鉴数据获取：**
1. 根据变量确定所需年鉴类型（国家/省级/城市/行业）
2. 确定数据在年鉴中的表号和位置
3. 使用WebFetch获取年鉴网页或下载链接
4. 解析表格数据（HTML表格抓取或PDF表格识别）
5. 保存为结构化CSV/Excel格式

**API数据获取（以World Bank为例）：**
```
API格式：https://api.worldbank.org/v2/country/{country}/indicator/{indicator}?format=json
```
1. 构建API URL（确定国家代码、指标代码、时间范围）
2. WebFetch获取JSON数据
3. 解析JSON并转换为表格格式
4. 保存为CSV

**其他公开数据源：**
- 国家统计局：http://www.stats.gov.cn
- 各省市统计局官网
- 行业协会官网

#### 3.3 数据获取判断

执行数据获取前，先尝试获取：
- 如果**能获取到数据** → 解析并保存
- 如果**获取失败**（页面需登录、无权限、页面不存在）→ 记录原因，生成数据获取指南
- 如果**数据需付费** → 生成详细获取指南

### Step 4: 数据整理与输出

| 输出 | 格式 | 内容 |
|-----|------|------|
| 数据说明文档 | .md | 变量定义、测度方式、数据来源、缺失情况 |
| 原始数据文件 | .xlsx/.csv | 采集/整理后的数据 |
| 数据获取指南 | .md | 无法直接获取时的详细说明（数据库、表名、字段名、获取方式） |
| 变量映射表 | .xlsx | 变量名-字段名-数据库表名对应 |

## 实施要点

1. **先尝试获取，再建议替代** — 优先尝试实际下载/抓取数据
2. **获取成功时**：保存原始数据 + 生成说明文档
3. **获取失败时**：详细记录失败原因 + 生成数据获取指南
4. **数据获取指南必须包含**：数据库名称、表名/指标名、字段名、获取方式、申请流程（如需）
5. **所有输出文件保持变量命名一致性**
6. **记录数据时间范围和缺失情况**
