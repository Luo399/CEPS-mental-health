## 1. 引用频次分析

### 1.1 年龄标准化引用量

社科论文引用积累速度远慢于STEM领域，必须按年龄标准化：

```
normalized_citations = total_citations / (current_year - publication_year + 1)
```

### 1.2 引用爆发检测

使用Kleinberg爆发检测算法的学术引用改编版：
- 对每篇论文，计算其历年引用量序列
- 定义"爆发"为某年引用量超过同年龄论文90百分位
- 追踪当前仍在爆发状态的论文（"active bursts"）
- 爆发论文通常代表领域关注热点

### 1.3 引用集中度

使用Gini系数衡量引用分布的集中程度：
- Gini > 0.7：少数论文垄断引用，存在"经典论文"主导
- 0.4 < Gini < 0.7：中等集中度，存在明显高被引群体
- Gini < 0.4：引用分布较均匀，领域处于分散探索阶段

### 1.4 期刊归一化影响

比较每篇论文的引用量与同期刊同年论文的中位数，消除期刊级别差异：
```
field_normalized_impact = paper_citations / median_citations(same_journal, same_year)
```

## 2. 关键词共现网络

### 2.1 共现矩阵构建

三种加权方式：

| 方式 | 公式 | 适用场景 |
|------|------|---------|
| 二值 | 1 if co-occur, 0 otherwise | 发现基本关联 |
| 频次 | 共现次数 | 衡量关联强度 |
| Jaccard | co-occur / (A ∪ B) | 消除高频词偏差 |

推荐：主要使用Jaccard归一化，二值作为对照验证。

### 2.2 中心度指标

| 指标 | 含义 | 选题意义 |
|------|------|---------|
| 度中心度 (Degree) | 与其他关键词的连接数 | 核心研究主题 |
| 中介中心度 (Betweenness) | 处于其他关键词对最短路径上的频率 | 跨领域桥接点 |
| 接近中心度 (Closeness) | 到所有其他关键词的平均距离 | 研究前沿核心 |

### 2.3 桥接关键词识别

桥接关键词 = 中介中心度 > 75百分位 且 度中心度 < 25百分位

这类关键词连接不同研究流但自身不是核心，代表跨领域整合的切入点。

### 2.4 网络阈值

- 共现次数 ≥ 2 才纳入网络（消除偶然共现噪声）
- 建议最大节点数 ≤ 200（超过时按频次截断）
- 大型网络的中介中心度使用近似算法（NetworkX的approximate_current_flow_betweenness_centrality）

### 2.5 可视化建议

- 使用Gephi或VOSviewer生成交互式网络图
- 报告中可用Mermaid语法展示小型子网络
- 节点大小=度中心度，颜色=社区归属，边粗细=Jaccard权重

## 3. 研究主题聚类

### 3.1 LDA主题模型

**预处理：**
- 中文：jieba分词 + 管理学术语自定义词典 + 停用词过滤
- 英文：标准tokenization + 停用词 + 词干化
- 构建文档-词矩阵

**参数优化：**
- 主题数选择：在[5, 20]范围内优化coherence score (C_v)
- alpha和eta使用auto模式
- passes=20, iterations=400确保收敛

**主题标注：**
- 每个主题取phi分布(主题-词分布)中权重最高的5个关键词
- 由AI根据关键词组合生成主题名称

**局限与注意：**
- LDA对短文本（如仅有摘要）效果可能不佳
- 中文分词质量直接影响LDA效果
- 需要多运行取稳定性最好的结果

### 3.2 社区检测（网络方法）

在关键词共现网络上应用Louvain/Leiden算法：
- 使用Jaccard加权的边权重
- 分辨率参数默认1.0，可根据需要调整（增大=更细粒度，减小=更粗粒度）
- 每个社区 = 一个研究主题
- 模块度Q > 0.3表示分区有意义

**优势：** 不依赖文本内容，基于关系结构
**劣势：** 对网络稀疏的边缘主题可能遗漏

### 3.3 嵌入聚类（可选增强）

使用多语言句嵌入：
- 模型：`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
- 支持中英文混合嵌入
- 聚类算法：HDBSCAN（密度聚类，无需预设类别数）
- 优势：可发现LDA遗漏的异常/新兴主题

### 3.4 共识策略

运行LDA和社区检测，交叉比对：
- 两方法一致的聚类 → 高置信度主题
- 两方法不一致 → 标记待审，可能代表边界模糊的研究领域
- 嵌入聚类结果作为补充参考

## 4. 时序趋势分析

### 4.1 年度频率计算

对每个关键词和主题聚类，计算逐年发文量。

### 4.2 趋势检测

**Mann-Kendall检验：**
- 非参数检验，适合小样本（每年几篇到几十篇）
- H0：无趋势；H1：存在单调趋势
- 显著性水平α=0.05

**Sen斜率估计：**
- 鲁棒的趋势幅度估计
- 不受异常值影响
- 公式：median[(x_j - x_i) / (j - i)] for all i < j

### 4.3 新兴性指标

近2年发文量与之前3年发文量的比率：
```
emergence_ratio = (papers_last_2_years / 2) / (papers_prev_3_years / 3)
```

### 4.4 动量评分

```
momentum = 0.4 * normalized_growth_rate + 0.3 * recent_acceleration + 0.3 * citation_velocity
```

其中：
- `normalized_growth_rate` = Sen斜率 / 平均频率（百分比增长）
- `recent_acceleration` = (近2年年均 - 前3年年均) / 前3年年均
- `citation_velocity` = 近期该主题论文的平均标准化引用率

### 4.5 分类阈值

| 分类 | 条件 |
|------|------|
| 新兴(Emerging) | momentum > 0.7 且 总论文 < 50 |
| 上升(Rising) | momentum > 0.5 且 总论文 ≥ 50 |
| 稳定(Stable) | 0.2 ≤ momentum ≤ 0.5 |
| 衰退(Fading) | momentum < 0.2 |

### 4.6 区域差异检测

分别计算中英文文献的趋势，比较：
- 中文上升但英文不存在的主题 → 跨语言空白
- 英文已成熟但中文刚开始的主题 → 理论引进机会
- 两者趋势一致的主题 → 全球性趋势

## 5. 研究空白识别

### 5.1 高中心度-低密度空白

**检测逻辑：**
1. 对每个关键词计算中介中心度和局部聚类系数
2. 筛选：中介中心度 > 75百分位 且 局部聚类系数 < 25百分位
3. 这类关键词位于不同研究流之间，但其邻域连接稀疏

**选题意义：** 两个成熟研究领域的交叉地带，整合空间大。

**示例：** "数字化转型"连接"组织文化"和"IT能力"，但三个概念同时出现的论文仅3篇。

### 5.2 理论-方法空白

**检测逻辑：**
1. 对每个聚类计算理论/定性论文与实证定量论文的比例
2. 比例 > 3:1 → 方法论空白（需要更多实证检验）
3. 比例 < 1:3 → 理论空白（需要更多概念框架）

**选题意义：**
- 方法论空白 → 可做实证检验研究
- 理论空白 → 可做理论建构研究

### 5.3 高增长-低文献空白

**检测逻辑：**
1. 筛选 momentum > 0.7 且 总论文数 < 30 的关键词
2. 高增长说明学界正在关注，低文献说明研究尚不充分

**选题意义：** 处于研究前沿的新兴领域，先发优势明显。

### 5.4 跨语言空白

**检测逻辑：**
1. 对统一关键词空间中的每个概念，计算中英文论文数量比
2. 比例 > 5:1 → 中文主导（可向国际推广）
3. 比例 < 1:5 → 英文主导（可在中国情境验证）

**选题意义：**
- 中文主导：将中国特色发现推向国际
- 英文主导：将国际理论在中国情境检验/拓展

### 5.5 引用停滞空白

**检测逻辑：**
1. 对每个主题，计算平均参考文献年龄
2. 平均年龄 > 8年 且 近期发文量下降
3. 说明该领域依赖旧文献，缺乏新贡献

**选题意义：** 成熟但停滞的领域，需要新视角刷新。

### 5.6 实践问题空白

**检测逻辑：**
1. 对每个聚类，计算理论/概念性论文占比
2. 占比 > 60% → 实践研究不足
3. 缺乏案例研究、应用验证、实践指南类论文

**选题意义：** 理论丰富但实践薄弱的领域，适合做应用导向研究。
