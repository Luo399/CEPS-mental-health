# 中文文献获取策略

CNKI（知网）没有公开API，中文文献采集需要采用替代策略。本文档详细说明各渠道的使用方法。

---

## 1. OpenAlex 中文覆盖

OpenAlex是目前最佳的免费学术API，对中国社科文献有一定覆盖。

### 优化策略

- 使用中文搜索词：`search=数字化转型`
- 语言过滤：`filter=language:zh`
- 期刊ISSN过滤：`filter=primary_location.source.issn:1002-5502`
- 概念过滤：使用OpenAlex的concepts字段筛选管理/经济/社会学类

### 局限性

- 中国社科期刊覆盖不完整，尤其是2018年以前的论文
- 部分中文论文的摘要和关键词可能缺失
- 引用数据不如英文文献完整

---

## 2. WebSearch 策略（中文文献核心补充）

### CNKI 搜索模式

```
"[研究领域]" "[期刊名称]" site:cnki.net
"[研究领域]" "[期刊名称]" filetype:pdf
"数字化转型" "管理世界" site:cnki.net
```

### 百度学术搜索模式

```
site:xueshu.baidu.com [研究领域] [期刊名称]
site:xueshu.baidu.com 数字化转型 组织韧性
```

### 万方数据搜索模式

```
"[研究领域]" site:wanfangdata.com.cn
```

### 搜索优化建议

- 每个目标期刊构造独立搜索查询
- 使用领域关键词+期刊名称的组合
- 限定年份范围：`2021..2025`
- 对搜索结果用WebFetch提取论文元数据

---

## 3. 百度学术 (xueshu.baidu.com)

### 优势
- 免费，覆盖中文期刊较好
- 提供中文论文的引用次数
- 部分论文有摘要信息

### 局限
- 搜索结果可能不完整
- 反爬机制较严格
- 引用数据不如CNKI准确

### 建议用法
- 作为OpenAlex的中文补充
- 用WebSearch构造查询，从结果页提取基本信息
- 对重要论文用WebFetch深入抓取详情页

---

## 4. Google Scholar 中文查询

适用于有英文摘要的中文论文：

```
"[中文关键词]" OR "[English keywords]" site:scholar.google.com
```

### 优势
- 可同时获取中英文文献
- 引用数据较准确
- 支持引用链追踪

### 局限
- 对纯中文论文覆盖有限
- 可能需要科学上网

---

## 5. CSSCI 期刊识别

CSSCI（中文社会科学引文索引）是中文社科论文质量的标志。

### 如何识别CSSCI期刊
- 南京大学中国社会科学研究评价中心发布年度目录
- 可通过WebSearch查询最新CSSCI来源期刊目录
- 本技能references/chinese-ss-journals.md中列出的期刊均为CSSCI来源

### CSSCI与选题的关系
- CSSCI期刊论文代表中文社科领域的高质量研究
- 选题挖掘应优先参考CSSCI期刊论文
- 非CSSCI期刊论文可作为补充，但不应作为主要分析对象

---

## 6. 降级策略

当某个数据源无法使用时：

```
CNKI不可用 → OpenAlex(zh) + 百度学术 + WebSearch
OpenAlex不可用 → WebSearch + 百度学术 + Google Scholar
WebSearch受限 → 依赖OpenAlex + 用户提供的本地文件
所有在线源受限 → 依赖用户提供的本地文献文件
```

---

## 7. 全文获取注意事项

- 本技能侧重文献元数据采集，不涉及全文下载
- CNKI/万方全文通常需要机构订阅
- 建议用户通过所在机构图书馆获取全文
- OpenAlex和Semantic Scholar提供的开放获取论文可直接访问
- 部分预印本可在作者个人主页或ResearchGate获取

---

## 8. 中英文文献合并策略

1. **独立采集**：中文和英文文献分别执行查询
2. **关键词对齐**：将中英文关键词映射到统一概念空间（Phase 2处理）
3. **分别统计**：中英文文献的引用模式差异大，需分别统计后再比较
4. **交叉验证**：用英文文献验证中文文献中的理论框架是否已在国际发表
5. **空白发现**：中英文文献的主题差异本身就是研究空白的重要来源
