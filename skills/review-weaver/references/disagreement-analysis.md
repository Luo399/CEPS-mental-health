# 分歧分析深度指南

当工作流执行到步骤 7 时，使用本指南进行分歧与缺口审计。

## 为什么分歧是综述的灵魂

分歧 = 研究缺口的前置信号。没有分歧讨论的综述缺乏深度，评审会质疑作者的批判性思维。分歧原因分析越具体，越能自然引出研究创新点。

## 分歧的五维分析框架

分析文献分歧时，从以下五个维度中选择适用的（通常 2-3 个就够了）：

### 1. 样本差异

| 检查点 | 示例 |
|---|---|
| 国家/地区差异 | 发达国家 vs 发展中国家 |
| 行业差异 | 制造业 vs 服务业 vs 高科技行业 |
| 企业规模差异 | 大企业 vs 中小企业 |
| 时间窗口差异 | 不同经济周期阶段 |

### 2. 方法差异

| 检查点 | 示例 |
|---|---|
| 识别策略 | OLS（相关）vs DID/IV/RDD（因果） |
| 数据层级 | 截面数据 vs 面板数据 |
| 变量度量 | 不同的核心变量代理指标 |
| 样本选择 | 全样本 vs 特定子样本 |

### 3. 变量测量差异

| 检查点 | 示例 |
|---|---|
| 自变量度量 | "创新"用专利数 vs 研发投入 vs 新产品销售 |
| 因变量度量 | "绩效"用 ROA vs Tobin's Q vs 全要素生产率 |
| 控制变量差异 | 不同模型控制的混淆变量不同 |

### 4. 情境差异

| 检查点 | 示例 |
|---|---|
| 制度环境 | 市场经济 vs 转型经济 |
| 政策环境 | 政策出台前 vs 政策出台后 |
| 市场结构 | 竞争市场 vs 垄断市场 |

### 5. 理论视角差异

| 检查点 | 示例 |
|---|---|
| 理论框架 | 资源基础观 vs 制度理论 vs 信号理论 |
| 机制解释 | 同一现象的不同理论解释 |
| 分析层次 | 企业层面 vs 行业层面 vs 宏观层面 |

## 分歧分析的写作模式

```
[明确矛盾] XX et al. (20XX) 发现 A 对 B 有显著正向影响，
然而 YY et al. (20XX) 在不同情境下得到了相反结论。

[分析原因] 这种分歧可能源于以下两方面：第一，[原因维度 1]，
XX 的样本来自[发达国家]，而 YY 聚焦于[发展中国家]，制度环境的
差异可能导致效应方向不同；第二，[原因维度 2]，XX 使用了
[OLS]方法仅能识别相关关系，而 YY 采用[DID]设计提供了因果推断，
方法的差异也可能是结论不一致的来源。

[判断权衡] 总体而言，[哪方证据更可信/在什么条件下哪方成立]。
```

## 分歧→缺口的映射逻辑

分歧分析的终极目标是自然引出研究缺口。映射逻辑：

```
分歧表现 → 分歧原因 → 分歧尚未解决的问题 → 本研究的切入点
```

**示例**：
- 分歧：数字化转型对就业的影响方向不一致
- 原因：样本行业差异 + 方法差异（相关 vs 因果）
- 未解决问题：缺乏制造业细分行业层面的因果证据
- 切入点：本研究使用 DID 方法，聚焦制造业细分行业

## 审计清单

对每个假设/主题，检查：

- [ ] 是否有明确的分歧讨论？
- [ ] 分歧是否用对比句式明确呈现？（"然而""与此不同""值得注意的是"）
- [ ] 分歧原因是否具体？（不是笼统的"因为研究不同"）
- [ ] 分歧双方是否都有代表性文献支撑？
- [ ] 分歧是否自然过渡到研究缺口？
- [ ] 缺口是否与用户的创新点对接？

## 常见问题

### 分歧过于笼统

**差**："不同研究得出了不同的结论。"
**好**："数字化转型对就业的影响存在显著的行业异质性：在制造业中表现为岗位替代（XX et al., 20XX），而在服务业中则表现为岗位创造（YY et al., 20XX），这种分歧可能源于两个行业的工作流程可自动化程度差异。"

### 只有分歧没有原因

**差**："XX 发现正向影响，YY 发现负向影响。"
**好**："XX 发现正向影响（OLS），YY 发现负向影响（IV）。这种分歧可能源于内生性问题——正向结论可能反映了反向因果。"

### 分歧与缺口脱节

**差**：讨论了很多分歧，但最后的缺口与分歧无关。
**好**：每个缺口都能追溯到前面讨论的某个分歧或局限性。
