# 推文内容模板

供推文使用。包含痛点模块、可复制提示词和实操要点。

---

## 痛点模块

> 综述写成流水账，一段接一段地"XX认为……YY发现……"，读完不知道作者想表达什么。文献堆砌没有逻辑，既看不出共识在哪里、分歧在哪里，也体现不出学术视野。最致命的是：综述写了 5000 字，和自己的研究假设毫无关系——评审看完只会问"那你的研究到底填补了什么缺口？"
>
> 更深层的问题：写综述前没有想清楚"这篇综述到底要论证什么"，直接上手堆文献，结果是形散神也散。

## 可复制提示词

### 子 Prompt A：分假设观点整合

```
你是一个文献综述写作助手。基于以下精读报告，按我的研究假设归类文献，生成综述主体。

输入：
- 精读报告：[技能2产出的reading-report.html内容或文字版]
- 我的研究主题：[论文题目]
- 我的核心假设：
  1. [假设1]
  2. [假设2]
  3. [假设3]

综述边界：
- 时间范围：[如 2015-2025]
- 学科范围：[如 创新经济学]
- 纳入标准：[如 仅限顶刊+高被引]

要求：
1. 动笔前先写一句话综述论证（在[领域]中，围绕[主题]……缺口……本研究拟……）
2. 以假设为骨架，每条假设下按"共识→分歧→研究缺口"结构组织
3. 有述有评，禁止简单罗列"XX认为"
4. 顶刊观点优先锚定，分歧点详细分析原因（样本/方法/测量/情境）
5. 每个假设末尾用过渡句引出我的研究
6. 保留作者+年份引用标注，首次出现标注期刊等级
7. 生成完整的 HTML 综述报告
8. 附带综述元数据（假设映射表、文献覆盖度、缺口清单）
9. 总篇幅 3000-5000 字
```

### 子 Prompt B：研究脉络梳理

```
你是一个文献综述写作助手。基于以下文献，梳理[研究领域]的研究脉络。

输入：
- 文献清单：[精读报告中的文献信息]
- 领域范围：[如"AI对企业绩效的影响"]
- 综述边界：[时间范围] / [纳入标准]

要求：
1. 按时间/方法演进划分 2-4 个研究阶段
2. 每个阶段标注标志性文献和代表性方法
3. 点明当前前沿方向和尚未充分探索的领域
4. 将本研究定位在脉络中
5. 篇幅控制在综述总篇幅的 15%-20%
6. 保留引用标注
```

### 子 Prompt C：段落流自检

```
你是一个学术写作审校助手。对以下综述段落执行段落流检查。

输入：
- [粘贴综述段落]

检查项：
1. 该段是否只有一条明确的信息？
2. 首句是否直接预告了该段的内容？
3. 每句话是否与前句有显式逻辑连接（因果/对比/递进/举例）？
4. 是否存在文献罗列（"XX认为…YY发现…"）？
5. 评述是否体现学术判断力（而非笼统的"好/坏"）？

输出：逐段指出问题并给出修改建议。
```

## 实操要点

### 1. 动笔前先想清楚一句话论证

综述不是"文献汇总"，是"用文献论证一个观点"。动笔前先回答：

> "在这篇综述中，我想让读者相信什么？"

如果答不出来，说明还没想清楚，先不要写。这一步直接决定了后面所有段落是否有灵魂。

### 2. 分歧点是综述灵魂

- 分歧 = 研究缺口的前置信号
- 没有分歧讨论的综述缺乏深度，评审会认为"作者没有批判性思维"
- 分歧原因分析越具体，越能引出你的研究创新点
- 用五维框架（样本/方法/测量/情境/理论视角）系统分析分歧原因

### 3. 顶刊观点前置

- 每个假设讨论的第一句，用顶刊文献"锚定"该假设的学术基础
- 读者会潜意识地给顶刊观点更高的权重
- 分歧讨论中，双方观点的代表性文献均应标注等级，让读者判断

### 4. 综述边界要显式声明

- 不设边界 = "你的综述到底在综述什么？"——评审的经典质疑
- 时间范围、学科范围、纳入标准三要素缺一不可
- 边界声明放在综述开头的"范围界定"段落

### 5. 段落流自检是最后的保险

- 写完后逐段做反向大纲：写下每段首句 → 检查是否服务于章节论点
- 不匹配的段落要么重写主题句，要么删除
- 特别警惕文献罗列段——一段超过 3 个引用但没有评述，就是罗列

### 6. 与前两个技能的衔接

- 技能 1（文献雷达）→ 筛选出核心文献清单
- 技能 2（精读拆解）→ 产出 8 维度精读报告
- 技能 3（观点织网）→ 基于精读报告生成综述框架
- 三个技能构成完整的文献综述生产链

## 新增功能说明（v2.0）

相比 v1.0，v2.0 新增以下能力：

1. **综述类型检测**：支持假设驱动、主题驱动、方法学综述三种类型，自动适配不同结构
2. **一句话论证先行**：动笔前强制构建核心论证句，避免"形散神散"
3. **综述边界定义**：时间/学科/纳入标准三要素，防止评审质疑范围模糊
4. **段落流检查**：反向大纲法检测段落质量，逐段修复问题
5. **动词校准规范**：5 级证据强度对应的动词表，精确表达主张强度
6. **目标风格适配**：中文核心 vs 英文 SSCI，自动调整引用密度和句式
7. **综述元数据输出**：假设映射表、文献覆盖度、缺口清单，全景掌握综述质量
8. **分片架构**：静态/动态分层，按需加载，后续扩展只需新增碎片
