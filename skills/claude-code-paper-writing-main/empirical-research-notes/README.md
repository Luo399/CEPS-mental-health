## 与书的关系

| 维度 | 主书《Claude Code 科研手记》 | 本系列笔记 |
|------|------------------------------|------------|
| 视角 | 方法论 + 心态 + 工具集成 | 一条具体的实证研究流水线 |
| 组织方式 | 16 章 + 6 附录,主题切片 | 按视频期数累积,流程切片 |

主书提供工具栈与心态,本系列把工具栈走一遍给你看。两者互为参照,可同步使用。

## 配套工具：EmpiricalWiki

[`empirical-wiki/`](empirical-wiki/) 是本系列笔记演示用的研究工具实体——把 Karpathy LLM-Wiki 模式特化到经管实证研究方向上。每期视频里出现的「ingest 文献」「跨论文累积测算变体」「研究设计→Stata 计划」等动作，都对应这套工具里的具体 skill。

读者可以按 [`empirical-wiki/README.md`](empirical-wiki/README.md) 里的 Quick Start 在自己的研究方向上跑一遍。如果只是想看流程不想动手，配套图书在 [`empirical-wiki/book/`](empirical-wiki/book/)，8 章入门讲清"为什么这么设计、具体怎么用"。
